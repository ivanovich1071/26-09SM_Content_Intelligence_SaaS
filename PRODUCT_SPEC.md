# PRODUCT SPEC — SM Content Intelligence SaaS

## 1. Суть

Подписочный сервис для маркетологов любой ниши: постоянно изучает рынок и конкурентов клиента и превращает эти данные
в конкретный контент-план и готовые тексты. Ценность не в написании текста, а в ответах на вопросы:
что происходит в нише, что делают конкуренты, какие темы растут, какие не раскрыты, где слабые места клиента,
какой контент делать следующим.

Продуктовая петля:
```
РЫНОК → данные рынка → аналитика → аудит → content gaps → темы → генерация → публикация → performance ─┐
  ▲                                                                                                    │
  └────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

**Не входит:** генерация видео, озвучка/TTS, подкасты, AI-аватары (HeyGen, ElevenLabs), realtime voice и звонки,
fine-tuning, white-label, CRM, сложный enterprise API.

## 2. Пользователи

| Роль | Задача |
|------|--------|
| Маркетолог / SMM малого и среднего бизнеса | Понять рынок, получить план и тексты |
| Руководитель маркетинга | Мониторинг конкурентов, еженедельный дайджест |
| Агентство | Несколько клиентов-проектов, отчёты |
| Посетитель сайта (лид) | Бесплатный аудит контента → регистрация |

## 3. Навигация

**Главное меню:** Обзор · Конкуренты · Лента · Темы · Сайты · Дайджест · Аудит контента · Контент Завод
**Настройки:** Компания · Источники · Brand Voice · Команда · Тариф · Использование · API (Enterprise)

## 4. Вкладки

### 4.1 Обзор
KPI за 7/30/90 дней: источники, конкуренты, публикации рынка, ваши публикации, новые темы, растущие темы.
Графики: динамика публикаций по неделям (вы vs конкуренты). Блоки: лучшие публикации (overperformance), изменения
конкурентов, топ content gaps, рекомендации (ссылки в Контент Завод).

### 4.2 Конкуренты
Добавление: название, сайт, Telegram, VK, YouTube, Instagram, LinkedIn, другие. Автопоиск соцсетей по ссылкам
с сайта (`extract_social` из VM_SM). Карточка конкурента (AI-профиль): позиционирование, ЦА, основные темы и
под-темы, форматы, tone of voice, частота публикаций, CTA, контентные паттерны. Вкладки карточки: профиль,
аналитика (медианы, ER), таймлайн изменений, контент.

### 4.3 Лента (Market Intelligence Feed)
Фильтры: конкурент, источник, дата, тема, формат, стадия воронки, CTA, engagement, overperformance, семантический
поиск. Для поста: текст, источник, дата, метрики, классификация, тема, hook, CTA.
**Карточка поста / AI-разбор:** hook, pain point, CTA, формат, funnel stage, аудитория, аргументация; почему пост
получил высокий отклик; что можно взять как паттерн; что НЕ стоит копировать.

### 4.4 Темы (Topic Intelligence)
Для темы: число публикаций, динамика, число конкурентов, средний и медианный engagement, лучшие публикации,
под-темы, связанные темы, насыщенность рынка. Дерево «тема → под-темы».
**Content Gap:** темы рынка → темы конкурентов → темы клиента → разница → gap. Визуально полосами (рынок vs клиент).
Qwen объясняет: почему gap обнаружен, какие данные его подтверждают, какие конкуренты раскрывают тему, какие форматы
используют, как можно раскрыть.

### 4.5 Сайты (Website Intelligence)
Отслеживание страниц услуг, блогов, статей, лендингов, новостей. Diff «было/стало» и AI-смысл изменения
(«сместили оффер с процесса на экономический результат»).

### 4.6 Дайджест
Еженедельный/ежемесячный/по расписанию: что произошло на рынке, новые темы, изменения конкурентов, лучшие публикации,
необычные контентные ходы, content gaps, изменения у клиента, рекомендации. Каналы: web, email, PDF; Telegram — позже.

### 4.7 Аудит контента (лид-магнит)
Форма: компания, сайт, Telegram, VK, другие источники → [Провести аудит].
Пайплайн: определение источников → сбор → извлечение → классификация → метрики → рыночный benchmark → аудит →
gap-анализ → рекомендации.

**Критерии MVP** (каждый: score 0–10, evidence, explanation, recommendations):

| Критерий | Что оценивается |
|----------|-----------------|
| Content Strategy | Регулярность, баланс тем и стадий воронки, связность каналов |
| Audience Fit | Насколько контент адресован целевой аудитории и её болям |
| Hook | Сила первых строк/заголовков |
| Value | Практическая польза, экспертиза, доказательства (кейсы, цифры) |
| Differentiation | Отличие от конкурентов по темам, углам и тону |
| CTA | Понятный следующий шаг, лид-магниты, связка соцсети → сайт → заявка |

Общий балл — взвешенная сумма, считает код, не модель. Балл не единственный результат: главное — проблемы, gaps и
возможности.
**Benchmark:** «ваш показатель vs медиана рынка vs сегмент сильных публикаций (верхний квартиль)». Если постов рынка
меньше порога (по умолчанию 30) — выводится «Недостаточно данных для надёжного рыночного сравнения». Benchmark не выдумывается.

Публичная версия: без регистрации, 1 аудит на IP/email в сутки, результат частично скрыт → регистрация.

### 4.8 Content Opportunities
После аудита: 10 тем, для каждой — почему, market evidence, customer gap, примеры конкурентов, рекомендуемые форматы.
Кнопка «В Контент Завод».

### 4.9 Контент Завод
Workflow: тема (из opportunities, gap, дайджеста или своя) → формат → brand voice → контекст (аудит, рынок, тема,
успешные паттерны, конкуренты) → Qwen → черновик → редактор → QA → финал → экспорт.
Форматы MVP: Telegram, Email (тема + прехедер + текст), LinkedIn, VK, Article.
Контекст модели обязательно включает: запрос, brand profile, brand voice, аудит, данные рынка, данные темы, успешные
паттерны, контекст конкурентов, требования формата. RAG ищет лучшие публикации по теме, паттерны, примеры конкурентов,
прошлый контент клиента. Контент конкурентов — аналитический контекст, не для копирования (QA проверяет близость).
Факты, которых нет в данных, — только шаблоном `[что подставить]`.

## 5. Центральный сценарий
Пользователь вводит сайт/Telegram → аудит → content score → проблемы → content gaps → 10 тем → выбор темы →
Контент Завод → Telegram/Email/Article → QA → готовый материал.

## 6. Монетизация

Воронка: бесплатный аудит → score → проблемы → gaps → opportunities → генерация → paywall → подписка.

| Тариф | Лимиты (предварительно, уточняются после замера себестоимости) |
|-------|------------------------------------------------------------------|
| Free | 1 аудит, 3 генерации, без мониторинга |
| Starter | 1 компания, 3 конкурента, 1 сайт, 5 источников, 20 аудитов/генераций… |
| Professional | 10 конкурентов, 5 сайтов, 20 источников, Topics, Digest, Content Factory |
| Agency | Несколько проектов/клиентов, расширенные лимиты, отчёты |
| Enterprise | Custom limits, API, SSO, права команды, свои коннекторы, private MCP |

MVP: тарифы и квоты в БД, тариф назначается в админке; оплата (bePaid / ЮKassa / Stripe через `PaymentProvider`) —
после измерения реальной себестоимости по `usage_events`.

## 7. Нефункциональные требования
- Мультитенантность: организация A никогда не видит данных B (API, запросы, автотесты).
- Все долгие операции — фоновые задачи со статусами; у фронта нет короткого таймаута на AI.
- Каждая дорогая операция пишется в `usage_events`.
- Каждый AI-результат валидируется JSON-схемой до сохранения.
- Язык интерфейса — русский (i18n-готовность), контент — на языке источника/клиента.
