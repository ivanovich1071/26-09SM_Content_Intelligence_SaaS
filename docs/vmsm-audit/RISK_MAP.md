# RISK MAP

| Риск | Вероятность | Влияние | Митигация |
|------|------------|---------|-----------|
| Telegram (`t.me/s`) и сайты режут частые запросы с одного IP | высокая при росте | нет данных у всех клиентов | Общий кэш публичных каналов между тенантами (`global_sources`), rate limit на домен, очередь с джиттером, прокси позже |
| Instagram/VK/YouTube требуют ключей и квот | высокая | неполное покрытие соцсетей | Коннекторы опциональные; честно показываем «источник не подключён»; ручной ввод метрик как в VM_SM |
| Себестоимость LLM на клиента выше тарифа | средняя | убыток | `usage_events` с первого дня, квоты до постановки задачи, дешёвая модель для разметки, кэш разметки общих постов |
| Утечка данных между организациями | низкая | критическое | `organization_id` везде, зависимость `get_current_org`, RLS в Postgres, автотесты cross-tenant на каждый эндпоинт |
| Разметка «для любой ниши» хуже, чем узкая | средняя | слабые темы и gap | Таксономия тем на организацию (предлагает модель, правит пользователь), eval-набор на 3–5 ниш |
| Модель выдумывает benchmark/факты | средняя | потеря доверия | Числа считает код; «недостаточно данных» при малой выборке; шаблоны `[…]` в текстах; QA-агент проверяет факты по контексту |
| Qwen через OpenRouter недоступен/сменил ID | средняя | простой AI-функций | Model ID в конфиге, fallback-модель в AI Router, повторы |
| Копирование контента конкурентов | средняя | юридический риск клиента | Промпты: конкуренты — аналитический контекст; QA проверяет близость текста к источникам (косинус) |
| Долгие AI-операции и таймауты во фронте | высокая | «зависания» | Все долгие операции — jobs со статусами и опросом/SSE |
| Персональные данные (email, telegram-аккаунты) | средняя | 152-ФЗ / закон РБ о ПД | Хранить минимум, политика конфиденциальности, удаление организации |
