# ROADMAP — эпики и критерии готовности

Принцип: vertical slices — каждый эпик даёт работающий функционал (DB + API + worker + UI + тесты).
После каждого эпика: тесты → запуск → проверка API и фронта → логи → документация → коммит.
Критическая регрессия — стоп, к следующему эпику не переходим.

- API `/topics`, `/topics/{id}`, `/topics/gaps` + AI-объяснение gap.
- UI: Topic Explorer, дерево тем, полосы gap.
- ✅ Сделано. Верхний уровень — темы таксономии организации (управляемые, сравнимые между периодами), под-темы —

## EPIC 9 — Content Strategy
- Content Strategist: 10 opportunities (почему, market evidence, customer gap, примеры конкурентов, форматы).
- UI: список opportunities → «В Контент Завод».
- ✅ Сделано. Таблица `content_opportunities` (миграция 0009), задача `build_opportunities`
  (`strategy/opportunities.py`). Кандидаты — темы таксономии с цифрами кода (`strategy/candidates.py`: доли, gap,
  тренд, ER к медиане рынка, насыщенность, под-темы, до 3 лучших уникальных постов рынка); score = пробел + ½ роста
  + бонус за ER − штраф за перенасыщенность. Content Strategist (`ai/prompts/strategy/system.md`) формулирует до 10
  тем только из кандидатов (не больше 2 на кандидата), с учётом слабых критериев и проблем аудита; тема без
  кандидата отбрасывается. Без модели — темы из кандидатов с положительным score. Меньше
  `STRATEGY_MIN_MARKET_POSTS` постов рынка — «Недостаточно данных». Запускается кнопкой, из отчёта аудита и сама
  после аудита организации (если данных рынка хватает). Новая подборка архивирует необработанные темы; статусы
  new → in_factory → done / dismissed. UI: вкладка «Стратегия», очередь тем в «Контент Заводе».
